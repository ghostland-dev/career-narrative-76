# CVCraft

Professional CV builder with templates and PDF export.

## Features

- Supabase authentication
- Modern CV templates
- PDF export (jsPDF, html2canvas)
- SEO with react-helmet-async

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase
- jsPDF

## Getting Started

```bash
git clone https://github.com/ghostland-dev/cvcraft.git
cd cvcraft
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
